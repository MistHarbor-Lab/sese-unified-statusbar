# 瑟瑟灵感状态栏

个人安装用。

1. 先安装并启用[酒馆助手](https://gitlab.com/novi028/JS-Slash-Runner)。
2. 在酒馆「扩展 → 安装扩展」粘贴本仓库地址，装好后刷新页面。同名旧脚本请先停用。
3. 搭配瑟瑟台账使用；使用其他数据库时，需切到 SQL 模式。
4. 进入角色聊天，打开右上角 ⚙ 设置 API 和表格。新开档导入模板；已有数据只修复模板，不要重填。
